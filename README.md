# Sarath Saseendran Pillai — Portfolio

A one-page portfolio website. No build step and no dependencies.

## Files
- `index.html` — page content and structure
- `css/style.css` — styles, colours (light and dark themes) and animations
- `js/main.js` — theme toggle, nav highlight, counters, cursor glow, project artwork, copy-email button

## View it
Double-click `index.html` to open it in your browser. An internet connection loads the Google Fonts; without it the page falls back to system fonts.

## Edit it
- Text: edit `index.html` (sections are marked `about`, `work`, `experience`, `skills`, `contact`).
- Colours: change the variables at the top of `css/style.css` (`--accent`, `--teal`, etc.).

## Put it online (free)
- **GitHub Pages:** create a repository, upload these files, then Settings → Pages → deploy from the main branch.
- **Netlify:** drag this folder onto app.netlify.com/drop.
- **Vercel:** import the folder or repository at vercel.com/new.
